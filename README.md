# READ ALOUD LAB

大学受験の比較的やさしいレベルで、音読・読解・構文理解を一体化した英語学習サイトです。

## 公開方法
1. GitHubで新しいRepositoryを作成
2. このフォルダ内のファイルをアップロード
3. Settings → Pages を開く
4. Deploy from a branch を選択
5. Branch を main / root に設定

## ファイル
- index.html : Lesson一覧
- lesson.html : 教材ページ
- style.css : デザイン
- data.json : 10本の教材データ
