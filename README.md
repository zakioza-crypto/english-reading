# READ ALOUD LAB

GitHub Pagesで公開できる英語音読教材サイトです。

## 5ファイル
- index.html
- lesson.html
- style.css
- data.json
- README.md

## GitHub Pagesで公開
1. GitHubで新しいRepositoryを作成
2. 上の4つのWebファイルをRepository直下にアップロード
3. Settings → Pages
4. SourceをDeploy from a branchに設定
5. Branchをmain、Folderを/(root)に設定
6. Save

数分後、表示されるURLでサイトを公開できます。

## 機能
- 10 Lesson
- 英文表示
- ブラウザ英語音声
- 読解4択問題
- 正解・不正解表示
- 解説表示
- 段落ごとの読解
- 1文ずつの構文解説
- 全文スラッシュリーディング
- 単語リスト
